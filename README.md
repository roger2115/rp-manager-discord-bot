# RP Manager

Discord bot system for roleplay character management.

## Stack

- Backend: Express + TypeScript + Prisma
- Bot: Discord.js
- Frontend: Next.js + TailwindCSS

## Structure

```
packages/
├── backend/    # API server
├── bot/        # Discord bot
└── frontend/   # Web dashboard
```

## Development

```bash
npm install

# Backend
cd packages/backend
npm run dev

# Bot
cd packages/bot
npm run dev

# Frontend
cd packages/frontend
npm run dev
```
